# 📱 Login Form em ReactJS

Um projeto de formulário de login responsivo desenvolvido em **ReactJS** com **Vite**, estilizado com **CSS** e utilizando ícones do Google Fonts (Material Symbols Rounded). O objetivo é simular uma página de login moderna, limpa e responsiva.

---

## 📸 Demonstração
![site-login-demonstracao](https://github.com/user-attachments/assets/67520a62-e1ad-4202-8bc9-b95e4eb97749)


> 📌 Simula um formulário de login com:
- Campo de e-mail
- Campo de senha com botão de exibir/ocultar senha
- Links de recuperação de senha e cadastro
- Login social via botões de terceiros (Google e Apple — layout ilustrativo)

---

## 🛠️ Tecnologias Utilizadas

- [ReactJS](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- CSS 
- Google Fonts (Material Symbols Rounded)

---

## 📦 Instalação

Clone o repositório:

git clone https://github.com/seu-usuario/seu-repositorio.git

▶️ Executando o Projeto
Para rodar em ambiente de desenvolvimento:
npm run dev

O servidor irá rodar no endereço:
http://localhost:5173


📌 Funcionalidades

✅ Campo de senha com ícone de exibir/ocultar

✅ Validação de campos obrigatórios via atributo required

✅ Layout responsivo e centralizado

✅ Ícones de e-mail, senha e olho do Material Symbols

✅ Botões de login social ilustrativos
